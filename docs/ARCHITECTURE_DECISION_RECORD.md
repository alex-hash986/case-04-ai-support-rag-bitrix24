# ADR-001. Модульный каркас AI-поддержки

Статус принят для Фазы 1. Подходы Case 01 и Case 02 к строгим DTO,
подтверждению ответа источником и предавторизации бюджета применяются
в структуре src из Case 03. Шлюз и WAL-хранилище принадлежат ядру.
Домен владеет маршрутом, поиском, проверкой ответа и портом Bitrix.
FastAPI связывает зависимости. Streamlit обращается к HTTP API.

Для пилота выбран один API-процесс на файл SQLite и журнал операций
с устойчивыми идентификаторами. Мок реализует семантику сверки.
Live REST или MCP реализуют тот же порт в Фазе 2. При неоднозначной доставке
live-адаптер должен сверять удалённое состояние перед повторной отправкой.

Индекс состоит из Markdown-секций и кэшированных эмбеддингов. Обновление
публикует снимок после завершения всех вычислений. Дословные предложения
из цитируемых секций ограничивают фактические утверждения в автоответах.
