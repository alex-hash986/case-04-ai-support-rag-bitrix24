# Интеграция с Bitrix24

## Подключение Telegram
Чтобы подключить Telegram к Bitrix24, откройте «Контакт-центр», выберите Telegram и привяжите бота к Открытой линии. Проверьте подключение тестовым сообщением в Telegram.

## Подключение WhatsApp
Чтобы подключить WhatsApp к Bitrix24, выберите доступный коннектор WhatsApp в «Контакт-центре» и назначьте Открытую линию.

## Чат сайта
Для подключения чата сайта настройте виджет Bitrix24 и выберите Открытую линию для входящих сообщений.

## Входящий вебхук REST API
Входящий вебхук Bitrix24 создаётся в разделе «Разработчикам». Созданные вебхуки доступны на вкладке «Интеграции».
